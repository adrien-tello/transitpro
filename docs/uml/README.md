One folder per module. Put the diagram source (`.drawio`, `.puml` or StarUML file) **and** a PNG export.

```
shared/     Shared class diagram of the central database (whole group)
booking/    Adrien   use-case, class, sequence, activity
fleet/      Fidel    use-case, class, sequence, activity
parcels/    Charllson use-case, class, sequence, activity
hr/         Joy      use-case, class, sequence, activity
```
